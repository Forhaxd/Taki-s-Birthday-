A small birthday surprise website made with HTML, CSS, and JavaScript.

## Project Files

Keep the following files together in the repository's root folder:

```text
your-repository/
├── index.html
├── style.css
├── 1.png
├── hat.png
```

## Publish with GitHub Pages

1. Upload `index.html`, `style.css`, all required image files, and this `README.md` to the same repository.
2. Open the repository's **Settings**.
3. Select **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then click **Save**.
6. Wait for GitHub Pages to publish the site. The website link will appear in the Pages section.

## Important

- The stylesheet must be named exactly `style.css` because `index.html` links to `./style.css`.
- Image filenames and letter case must match the names used in `index.html`.
- Do not upload only `index.html` and `style.css`; the image files listed above are also needed for the complete design.
- If you change any image filename, update the matching `src` in `index.html`.
